组件全状态铺开页

把项目自研组件与 Adminator 皮肤组件的全部状态并排铺开，开发时一眼检查控件的默认 / 悬停 / 聚焦 / 禁用 / 加载 / 错误观感。

这是什么页：开发期自查用的静态铺开页，不是线上功能页；它只由本目录下的一个 index.html 构成， 额外引用的全部是线上真实资源（../css/app.css 与 Adminator 皮肤、../js/core.js 与组件脚本）， 因此这里看到的观感就是线上真实观感。
怎么用：用浏览器打开 /static/preview-states/index.html（登录后由应用直接静态托管）， 点右上角「切换深色」即可对照同一批状态在暗色下的表现。
维护约定：新增一个组件或新增一个状态时，同步把状态铺到本页对应小节； 改动组件样式后先来这里扫一遍所有状态，再进线上页面。
说明：静态页冻结不了 :hover，凡「悬停态」一律给虚线占位框并标注「悬停态请真机悬停」； 「聚焦态」用页面内复刻类（.ps-*-focus）展示该状态的外观，真机由 :focus-visible / :focus 自动触发。

本页的验证与已知 app.css 缺陷（只记录、不修）：
· 全部引用的类名已对 app.css + adminator.css 真实存在性核对（抽检结论见任务汇报）。
· 页面内 id 无重复；<link>/<script> 相对路径指向的文件真实存在。
· .set-ok：app.css 无此规则（只有 .set-bad）→ 该状态无样式。
· .select-field.is-disabled：app.css 只为 .multiselect-field.is-disabled 写了 opacity:.6， 单选下拉的根 .is-disabled 无样式（仅靠触发器 :disabled 表现）。
· Adminator 的 .badge.success/.danger/.purple 对比度不足（app.css 注释自述 2.07–3.44:1）， 项目内已改用 .badge--ok/--bad/…；上表保留原始档仅供对照。
