正态分布调参 · 组件方案选型页 拖一拖再挑 · 四方案同参同源 账号数（喂 σ 放大注记） 个
四个方案编辑的是同一组参数：μ 峰值中心区间（占有效窗口位置 %，默认 40~60）与 σ 散布宽度区间（占窗口宽度 %，默认 15~25），每天在区间内各取一点、全体账号共享。原型窗口固定 06:30~07:50、掐头去尾各 3 分钟（放大裁剪区便于观察；实际默认 1 分钟）；账号数只影响 σ 放大注记（n>20 时 σ×(1+log₂(n/20))，封顶窗口/3）。每张卡可独立试拖、可重置。方案 E 是单点派：抓住峰尖一个点，左右移峰值、上下改散布。

方案 A · 双通道编辑器（曲线 + 两条拖拽通道）

推荐

曲线区只负责"看"（包络 + 中位钟形 + μ 竖虚线），"调"全部发生在下方两条通道上：μ 通道刻度与曲线时间轴对齐（拖手柄改边界、拖带体整体平移），σ 通道是宽度标尺（只拖手柄）。

优点　位置与宽度语义各自成行不混淆；手柄大、触屏友好；通道是 DOM 元件，键盘（Tab + 方向键）与读屏有平权路径。 代价　卡内常驻一块高度；通道与曲线分离，视线要在两者间往返。

浅带 = 区间内所有可能的钟形（包络）· 实线 = 区间中点的名义钟形 · 虚线 = 按账号数放大后的实际钟形（n>20 才出现）

方案 B · 一体画布（全部手柄在图内）

没有独立通道：μ 区间是时间轴上的胶囊带（拖柄改边界、拖带体平移）；σ 画成峰值下方的宽度括号（拖左右柄等比缩放整个 σ 区间）。

优点　最直接的操纵感，拖动即见钟形变形；整卡高度最省。 代价　σ 只能整体等比缩放（无法单独改 min/max，精调仍要数字框）；手柄小、触屏命中难；无障碍完全依赖旁路数字框。

方案 C · 时间轴条带（无曲线、表单优先）

一根时间轴讲完所有事：斜纹 = 掐头/去尾裁剪区，深带 = μ 区间（拖柄/拖带体），外围虚线晕 = σ 宽度（拖晕边等比缩放），下方数字框做精调、双向同步。

优点　与「签到窗口」心智同构（都是一天里的时间轴）；最紧凑，掐头去尾与峰值的相对关系一眼可见。 代价　没有钟形直觉，「正态拟人」的形状感丢失；μ 块与 σ 晕同轴叠放，靠命中优先级防误拖。

方案 D · 触发器 + 弹窗（掐头/去尾同款家族交互）

卡内零占位：触发器只显示当前值，点击弹窗编辑（小曲线 + 两条通道 + 数字框）。确定才生效、取消不留痕——与「掐头/去尾」弹窗家族同一契约。

优点　卡片保持现在的密度；改动有明确的确定/回退边界；弹窗内可复用方案 A 的通道元件。 代价　默认看不见曲线与当前值的位置含义，调参前多一层点击；弹窗空间有限。

方案 E · 峰尖拖拽（单点 XY：上下 = 散布，左右 = 峰值）

新增

整块画布就是一个手柄：抓住峰尖圆点拖——左右移峰值时刻，上下改散布（上尖下扁）；拖轴上底座的两端同样调散布；空白处按下等于整体推移。纵轴有刻度：人/分钟，高峰一分会过几个人一眼可读。下方按「顶点钟点 ± 半径」设置峰值区间——半径一值定宽、顶点不动；散布按 ±分钟。前端换算成整数 % 提交——API 四键（mu/sigma_min/max_pct）不动。

优点　一个点同时驱动两个参数，手不用在通道间换位；「抓着钟形变形」与直觉完全同构；宽度不再是抽象 %，染色与底座对着时间刻度直接可读；峰值区间「顶点 ± 半径」一值定宽。 代价　区间恒以峰尖为中点、半径一值定宽（不能单独偏移单边）；单点读不出区间四键；σ 上限贴着窗口/3 封顶（再大也会被 σ_eff 吃掉）。

纵轴 = 预计每分钟签到人数（随峰形自动缩放）· 实线 = 名义钟形 · 深色核心 = ±1σ（约 68% 账号）· 轴上底座 = 散布宽度（短须 = σ 区间两端）· 虚线 = 按账号数放大后的实际钟形
