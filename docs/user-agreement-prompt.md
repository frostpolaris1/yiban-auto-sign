# 用户协议撰写提示词

> 用途：将本提示词发给任意 AI（大模型），即可生成一份可放入注册页弹窗的《用户协议》文本。
> 生成后把内容填入 `web/templates/login.html` 的 `#agreement-content` 区块（改代码维护，不在管理面板修改）。

---

## 提示词正文（复制以下全部内容）

请以专业但通俗的中文，为我撰写一份适用于"易班自动签到"网页服务的《用户协议》。目标读者是普通在校学生（非法律专业人士），要求：

**项目背景（必须基于以下事实撰写，不得虚构）：**
1. 这是一个自建的易班（校园信息平台）自动签到辅助服务，注册用户在网页上提交自己的易班账号（手机号）、登录密码、设备型号与设备识别码，由系统在每日签到窗口自动代为签到。
2. 用户提交的账号需经管理员人工审核，通过后才会参与自动签到；审核不通过会注明理由，用户可修改后重新提交。
3. 注册无需邀请码，不提供邮箱验证码服务；注册仅需邮箱 + 密码，一个用户限提交一套易班账号。
4. 密码以不可逆哈希形式存储，任何管理员（含站长本人）都无法查看明文密码；账号密码仅用于自动签到，不用于任何其他用途。
5. 服务无固定域名，属于个人运维的小规模工具，不保证稳定性与可用性，可能因平台规则变化随时调整或停止。

**必须包含的章节：**
一、服务说明（做什么、不做什么）
二、账号提交与审核（提交流程、一人一号、审核/拒绝/重新提交规则）
三、信息收集与使用（收集哪些信息、用途、存储方式、不向第三方提供）
四、信息安全与责任（密码不可见、请勿共用账号、泄露风险提示）
五、免责声明（自动签到属于平台规则边缘的辅助操作，存在账号受限或处罚的风险；因使用本服务产生的一切后果由用户自愿承担；本服务不保证签到必定成功）
六、用户义务（提供真实信息、遵守学校与平台规定、及时更新失效账号）
七、服务变更与终止（可随时调整或停止，不另行通知）
八、其他（协议随服务更新、注册即视为同意）

**写作要求：**
- 全文 800～1200 字，分节清晰，每节 1～3 个短句，避免大段法律套话。
- 语言直白，不使用"鉴于""兹有""甲方乙方"等生僻法律措辞，称呼用户为"你"，服务方为"本服务"。
- 免责声明必须诚实、明确，不夸大服务能力，不承诺签到成功率。
- 不得出现任何与本项目事实不符的内容（如"数据加密传输"若无、邀请码、人工客服、退款、会员等一律不写）。
- 输出为可直接粘贴进 HTML 的纯文本（每个段落一个 `<p>`，章节号用中文数字"一、二、…"），不要输出 markdown 代码块外壳。
