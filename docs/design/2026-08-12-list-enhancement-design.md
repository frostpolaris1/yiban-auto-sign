# 管理端列表组件增强设计（限高 + 搜索 + 人数显示）

日期：2026-08-12
状态：已通过预览确认（用户调整：搜索框放标题栏右侧；限高最终效果以实装后验证为准）

## 目标

管理端 5 个表格控件在大量数据下可快速检索定位，组件高度受控，标题处显示表格人数。

## 范围

- 仅 `web/templates/index.html`（管理端）
- 用户端 user.html 不动（单账号无规模问题）；后端 API 零改动

## 设计

### 1. 表格清单与改造点

| 表格 | 人数显示 | 搜索字段 |
|------|---------|---------|
| 待处理账号 | 已有「N 个待处理」（保留） | 名称/手机号/用户名 |
| 正常账号 | 新增「N 个」 | 名称/手机号/用户名 |
| 待审核用户 | 已有「（N 人待审核）」（保留） | 邮箱 |
| 正式用户 | 新增「（N 人）」 | 邮箱 |
| 空用户 | 已有「（N 人）」（保留） | 邮箱 |

### 2. 标题栏布局（统一模式）

每个表格的标题行改为 flex 布局：

```
[标题] [人数徽章]          —— 左侧
[搜索框]                   —— 右侧（宽度 w-40 md:w-56，手机端可换行）
```

- 搜索框 placeholder 按表定制：「搜索名称 / 手机号 / 用户名…」/「搜索邮箱…」
- 搜索框样式与现有输入框一致（bg-white dark:bg-zinc-900 border rounded-lg text-sm）
- 手机端空间不足时标题行允许换行（flex-wrap）

### 3. 高度控制

- 每个表格滚动容器（现有 `overflow-x-auto` div）追加 `max-h-[420px] overflow-y-auto`
- `<thead>` 行追加 `sticky top-0 z-10`（现有 thead 已有背景色，吸顶不透明）
- 空状态提示在滚动容器外，不受影响

### 4. 搜索交互

- 5 个搜索框，实时过滤（input 事件），只过滤当前组
- 搜索词存内存变量，10 秒轮询刷新后过滤依然生效
- 搜索匹配：账号表 = name/phone/owner/owner_display 的 includes；用户表 = email includes（小写不敏感）
- 搜索无结果：表格区显示「无匹配结果」；有结果恢复
- 人数徽章：未搜索显示总数；搜索中显示「匹配 N / 共 M」

### 5. 版本与文档

- 功能新增：0.9.7 → 0.10.0（大版本保持 0.x，用户许可 0.10.x 序列）
- CHANGELOG.md（网页端通俗版）与 docs/CHANGELOG-full.md（内部详细版）同步更新
