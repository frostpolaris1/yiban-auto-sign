# 易班自动签到 · 使用说明书

## 一、这是什么

一个自动完成易班早操签到的网页服务：注册后提交你的易班账号，系统会在每天签到窗口自动代为签到，并可以在网页上查看每日签到结果。

## 二、注册与登录

1. 打开网址（管理员会告知地址），点击「注册」
2. 填写**邮箱**和**密码**（密码至少 10 位，且需包含大写/小写字母、数字、符号中的至少两类），勾选同意《用户协议》
3. 注册成功后用邮箱登录
4. 登录后顶部会显示你的邮箱前缀

> 提示：注册邮箱不可修改，密码可以随时在页面底部「修改密码」处自助修改。

## 三、提交易班账号

1. 登录后进入「提交我的易班账号」
2. 填写：名称/备注（可选）、**易班手机号**、**易班登录密码**、设备型号与设备识别码（学校开启设备绑定时必填）
3. 每个用户**限提交一个账号**，提交后等待管理员审核
4. 审核不通过时会显示拒绝理由，修改后可重新提交

## 四、查看签到情况

- **我的账号与签到情况**：显示账号状态（⏳ 准备签到 / ✅ 今日成功 / ❌ 今日失败 / 🔄 重试中 / ➖ 跳过）和排队人数
- **签到日历**：每月一页，可翻看任意月份
  - 🟢 绿点 = 当天签到成功
  - 🔴 红点 = 当天签到失败
  - ⚪ 灰点 = 周日休息（无需签到）
  - 空白 = 当天无记录
  - 点击任意日期可查看当天的签到日志

## 五、常见问题

- **为什么我的账号还没签到？** 账号需要管理员审核通过后才会参与自动签到
- **签到失败怎么办？** 检查易班密码是否修改、设备绑定是否变更，然后编辑账号更新信息；也可以联系管理员手动签到
- **排队是什么意思？** 多个账号按顺序依次签到，排队数字表示你前面还有几个账号

## 六、管理员功能（仅管理员可见）

- **账号管理**：查看/审核用户提交的账号（通过/拒绝并留言理由）、添加/编辑/删除账号、调整签到顺序、手动签到
- **用户管理**：查看注册用户、设置/取消管理员、重置密码、清空或删除用户
- **系统设置**：随机延迟（防风控，修改自动保存）、连通性检测、服务器时间、修改自己的密码、全局公告

## 七、安全说明

- 你的易班密码以加密方式存储（AES-256-GCM），网页界面不会显示明文；请勿泄露服务器密钥文件（`YIBAN_ACCOUNTS_KEY`），持有密钥者可解密
- 请勿与他人共用账号密码
- 自动签到属于平台规则边缘的辅助操作，使用前请了解并自愿承担相关风险
